# Leon – Creative Agency Website

A modern and responsive landing page for a creative digital agency, built using **HTML5 and CSS3**.

This project is based on the Leon Template One design by Elzero Web School. It was developed as a front-end practice project to improve my understanding of HTML structure, CSS styling, Flexbox, CSS Grid, and responsive web design.

## Features

- Clean and minimal user interface.
- Responsive layout for different screen sizes.
- Navigation menu with hover interactions.
- Smooth scrolling between sections.
- CSS Grid and Flexbox layouts.
- Reusable CSS variables and components.
- Custom styling using pseudo-elements and pseudo-classes.

## Website Sections

- **Header:** Logo and navigation menu.
- **Landing:** Main introduction section.
- **Features:** Highlights the agency's main features.
- **Services:** Showcases the services offered.
- **Portfolio:** Displays selected projects.
- **About:** Introduces the agency.
- **Contact:** Contact information and social media links.
- **Footer:** Copyright information.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Media Queries
